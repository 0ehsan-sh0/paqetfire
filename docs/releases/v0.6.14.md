## Fixes and improvements

- Fix LAN SOCKS5 authentication: Xray now receives credentials in its supported `accounts` field, so mobile clients can authenticate with the saved username and password.
- Clarify that LAN sharing must be saved and the connection started before the configured endpoint is available.
- Improve desktop card and panel widths across the connection, routing, diagnostics, and settings pages.
- Add a real Xray SOCKS5 handshake regression script that verifies valid credentials are accepted and an incorrect password is rejected.

## Using LAN sharing

Enable LAN sharing, enter a username and a password of at least eight characters, then select **Save and connect**. Configure a SOCKS5 profile in your mobile client using the displayed LAN address, port, and saved credentials. Leaving the password field blank after saving preserves the existing password.
