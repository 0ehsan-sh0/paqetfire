# PaqetFire v0.6.27

This release keeps the route up by itself, connects faster, shows what it is
doing, and updates every bundled component to its latest stable release.

## Reliability

- The broker now owns recovery. When Paqet crashes or stalls, only Paqet is
  restarted (after 1, 2, 5, 10, then every 30 seconds) while Xray and ProxiFyre
  keep running, so routed traffic fails closed instead of going direct. After
  five failed attempts the route is released to its safe state.
- Network changes and sleep/resume are handled by the broker, even when the
  desktop app is closed. Only engines whose configuration actually changed are
  restarted; DHCP renewals and IPv6 address rotation no longer drop the route.
- A stalled tunnel is detected in about 12 seconds instead of 20–36, and
  restart backoff is capped at one minute while a network is available.
- The broker remembers that you want to stay connected and reconnects after a
  service restart or upgrade.
- Mobile hotspot turning itself off no longer prevents transport recovery; the
  hotspot share is paused with a notice instead.
- Automatic adapter selection follows the Windows route to the server, so a
  docked Ethernet port without internet no longer wins over working Wi-Fi.
- Cancel and Disconnect take effect during a connect instead of waiting for it.

## Speed

- Typical connects are faster: Paqet and Xray start together, engine files are
  re-hashed only when they change, firewall repair runs in the background,
  readiness uses the listener table instead of timed connection attempts, and
  ProxiFyre is ready when its log says so instead of after a fixed wait.
- New profiles use FakeDNS, saving one tunnel round trip per new domain.
- New profiles block QUIC for tunneled traffic, which measured about twice the
  download throughput over Paqet. Direct destinations, such as Iranian sites,
  keep HTTP/3.
- When the server has no IPv6 egress, later connects stop handing applications
  AAAA records that would stall before falling back to IPv4.
- The server address is resolved by querying all resolvers in parallel, and
  restarts reuse the last address without a lookup.

## Routing data and blocking

- Settings → Routing data downloads the daily Iran-v2ray-rules GeoIP/GeoSite
  release, verifies its checksums, and tests it with the bundled Xray before
  using it from the next connection. It adds Persian ad networks, many more
  Iranian sites for Iran — Direct, and malware categories. The files bundled
  with Xray remain the fallback.
- New option: Block malware, phishing and cryptominers (on for new profiles,
  active once updated routing data is installed).

## Security

- `%ProgramData%\PaqetFire` is now owned by SYSTEM with a protected DACL, set by
  the installer and checked at every broker start. Previously it inherited the
  `%ProgramData%` permission that lets standard users create entries, so a user
  could plant files before the broker created its own. Planted links, hard
  links, and untrusted entries are removed.
- Xray ignores machine-wide `xray.*` and `XRAY_*` environment variables, so
  they cannot redirect its data files or merge extra configuration.

## Desktop

- Overview shows each connect step with elapsed time and a Cancel button, and
  "Reconnecting transport (attempt N)" during recovery.
- Broker errors are shown with their actual message and a matching action
  instead of "Broker unavailable"; the app reconnects to the broker by itself.
- Save, Verify, and profile actions no longer fail at random while connected.
- A Get started checklist installs missing prerequisites one after another and
  re-checks them automatically.
- Profiles: New profile, import from the clipboard, import alongside existing
  profiles or replacing them, a profile switcher on Overview and in the tray,
  and Test server to check reachability before connecting.
- Hotspot sharing shows a scannable QR code.
- The tray icon shows the connection state, opens on a single click, switches
  profiles, and notifies you when the route drops, recovers, or the kill switch
  blocks traffic. Starting with Windows opens in the tray, and launching the app
  again restores the running window.
- Settings switches save immediately. Network detection no longer freezes the
  window. Live statistics pause while the window is hidden.

## Updated components

- ProxiFyre 2.6.1 → 2.6.4: fewer repeated process lookups, bounded log
  rotation, and Program Files permission fixes.
- Microsoft Visual C++ runtime installer 14.44 → 14.51.36247.
- Windows App SDK WinUI 2.3.9, .NET runtime packages 10.0.13, xUnit v3 on
  Microsoft Testing Platform, and current GitHub Actions.
- Paqet v1.0.0-alpha.21, Xray 26.3.27, and Windows Packet Filter 3.6.2 were
  already the latest stable releases.

Upgrade using the MSI. The desktop and broker use IPC v13 and must be upgraded
together, which the MSI does. Profiles saved before this release keep their
FakeDNS, QUIC, and malware-blocking choices.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
