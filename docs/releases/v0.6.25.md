# PaqetFire v0.6.25

This release fixes routed applications losing connectivity while the Windows
Firewall Private or Public profile is enabled.

- ProxiFyre redirects captured traffic to local listeners that Windows treats
  as inbound on the physical adapter, so it depends on the installer's
  program-scoped firewall exceptions. Windows Installer deletes those rules by
  name whenever any PaqetFire package is uninstalled, and a firewall reset
  deletes them too; afterwards the firewall silently dropped redirected traffic.
- Before every connect, the broker now restores any of the four engine rules
  (ProxiFyre TCP/UDP and LAN SOCKS5 TCP/UDP) that are missing, disabled,
  duplicated, or point at another path. Restored rules keep the installer's
  names, so uninstalling the MSI still removes them. A firewall that refuses
  the change is logged and does not block connecting.

Upgrade using the MSI. IPC, engine, and driver versions are unchanged.

Local validation: 205 tests passed on Windows; six environment-dependent tests
were skipped. The release workflow also runs tests with the staged payload
before publishing.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
