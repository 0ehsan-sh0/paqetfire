# PaqetFire v0.6.26

This release encrypts DNS, recovers dead tunnels automatically, and hardens the
local engine chain.

## DNS

- Captured DNS lookups are answered by Xray over DNS-over-HTTPS through Paqet
  (Cloudflare by default; Google, Quad9, or the System resolver are
  selectable). Local, Iranian, and custom direct domains keep using the
  network's own resolver. Previously, with the Iran preset, lookups usually
  went to the ISP resolver in plaintext.
- Optional FakeDNS answers lookups instantly with placeholder addresses and
  lets the Paqet server resolve the real name, saving one tunnel round trip
  per new domain. It is off by default.
- Verify route has a new DNS leak check that compares the resolver answering
  through the route with the network's resolver.
- The Windows DNS cache is flushed whenever the route changes.

## Reliability

- A tunnel watchdog probes the Paqet carrier while connected. When the server
  stops answering, the app shows "Tunnel not responding" and restarts the Paqet
  transport with backoff; routed traffic stays on the route meanwhile.
- The broker resolves the server host name itself, so Paqet no longer fails to
  start when its own lookup is captured into a route that is not up yet.
- Paqet and Xray now end with the broker process, leftover engines are stopped
  at startup, and the broker service restarts automatically after a failure.

## Security and performance

- The local SOCKS5 hops between ProxiFyre, Xray, and Paqet require
  machine-generated credentials, so other local processes cannot borrow the
  route over TCP.
- Paqet logs at `warn` by default; `info` recorded every destination.
  Existing profiles keep their saved level.
- Blank KCP windows now default to 1024 receive and 512 send packets instead
  of Paqet's 512/128, raising the throughput ceiling on high-latency routes.

## Diagnostics

- Diagnostics has a Copy diagnostics button that produces a report for bug
  reports with secrets, the server host, and public IP addresses redacted.

Upgrade using the MSI. The desktop and broker use IPC v12 and must be upgraded
together, which the MSI does. Engine and driver versions are unchanged.

Local validation: 259 tests passed on Windows with the staged engine payload;
four tests that require an elevated run were skipped. The release workflow
also runs tests with the staged payload before publishing.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
