## Improvements

- Prevent slow desktop clients from blocking broker health monitoring.
- Bound IPC requests and Xray validation, and clean up timed-out connections and processes.
- Protect temporary credential files before writing, including rollback and machine-settings copies.
- Keep the current route and guard running until configuration persistence succeeds.
- Reduce idle settings decryption and prerequisite scans while retaining fresh connection checks.
- Improve save feedback, prevent duplicate saves, and display the correct application-routing scope.
- Show pending configuration changes and field errors; adapt forms for narrow windows and text scaling.
- Add broker/desktop regression coverage and pull-request build validation.

## Validation and limitations

The local Release build passed without warnings or errors, with 67 tests passing.
Two protected-file lifecycle tests require Administrator/SYSTEM and are included
in the Windows CI suite. Live accessibility and packet-capture leak checks have
not been performed. The routing kill switch remains limited to ProxiFyre-covered
traffic; changing its rules requires a process restart.

Windows installers remain unsigned development builds.
